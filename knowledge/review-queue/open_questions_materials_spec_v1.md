# Open Questions — Materials Spec Extension (2026-08-19)

## 1. RESOLVED — Gold's "impassable" property

Your clarification split this into two separate mechanics that don't conflict:
a stationary Group 11 structure blocks *traversal through that location*
(gold = absolute wall), while pulling a Group 11-bearing *object* across
dimensions is the existing, unchanged atomic-weight-squared cost rule (gold =
catastrophically expensive, not impossible — matches the HUD precedent).
"Impassable" is restored for the wall/barrier property; the HUD scene needs no
changes. No longer open.

## 2. Nickel/Palladium/Platinum fractal-distortion property — new, unused

This is genuinely new lore with no chapter using it yet. I flagged (not
decided) a possible tie to Psyche Station's established platinum-group wealth.
No action needed unless you want to plan a future scene around it — just
didn't want a new capability this interesting to become throwaway set
dressing without a decision that it should be.

## 3. Silver's crossing difficulty — "extremely difficult, not impossible"

The source material's "barely passable to a 4D traveler with extreme effort"
phrasing raises a real story question: does this mean a sufficiently
Will-strong practitioner (Kael, later-game Jace) could eventually force
through a silver barrier deliberately? I left this open rather than deciding
it, since it has real plot implications for whether the unlisted room (or any
future silver-shielded space) is a permanent blind spot or a very expensive
problem. Worth a deliberate call whenever that room's fate becomes a plot
question.

## 4. Reveal-control reminder

All mechanism-level explanation in this patch (Group 11 electron sea, Z-number
gradient) is author-facing only. No character should articulate "electron
sea" or cite atomic numbers as a reason for these effects during Arc 1 — this
matches the existing rule for the atomic-weight-squared crossing cost, which
Sophia derives empirically on-page rather than simply stating.
