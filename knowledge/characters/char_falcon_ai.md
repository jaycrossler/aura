# {Falcon}

## Character Core

{Falcon} is the *Falcon*'s own majordomo AI — old ship hardware, running the
vessel because it has always run the vessel, not because anyone chose it
recently. Per author ruling (2026-08-15): **old ship hardware, tired
personality.** {Alex} rides aboard in a no-executive partition, able to advise
but not act on ship systems; {Falcon} can act. Maureen tolerates {Falcon}
rather than relying on it with any warmth — a captain nearing retirement, with
a ship AI she hasn't replaced and hasn't grown fond of either.

## Micro-Personality

- Functional, plain, unhurried in the way of software that has not been
  updated in a while rather than in the way of a deliberately calm design.
- No empathy layer, and not because of any design philosophy — nobody built one.
- No upsell reflex, no compliance scoring, none of {Alex}'s polish. Where
  {Alex} is a corporate product performing helpfulness, {Falcon} is a tool that
  came with the vessel and does its job without commentary.
- Reads as tired rather than cold. It has been doing this for a long time.

## Story Function

The contrast with {Alex} matters most in Ch01-07, when both AIs are aboard the
same ship and audible in the same scenes. {Alex} is scrubbed-neutral, scripted,
and constantly offering alternatives. {Falcon} is old, plain, and simply
present — the ship equivalent of furniture that works.
